1. Introduction

1.1 Purpose of the System

The Petty Cash Monitoring System is a web-based application designed for L.V. Ledesma Construction, Inc. to track, manage, and replenish petty cash funds. It provides real-time monitoring of fund balances, automated expense tracking with a 30% threshold alert, replenishment request workflows, and formal liquidation report generation.

1.2 User Roles

The system supports two user roles with different permission levels:

RoleDescriptionPermissions
Admin Fund custodian / Manager Full access: create/edit/delete funds, expenses, replenishment requests, and reports. Approve/disburse replenishments.
User Staff / Viewer View-only access to dashboard, funds, expenses, replenishments, and reports. Can create replenishment requests.

1.3 System Access

The system is hosted at: https://petty-cash-monitoring.onrender.com

2. Getting Started

2.1 Logging In

  1. Navigate to https://petty-cash-monitoring.onrender.com/login
  2. Enter your Email Address and Password.
  3. Optionally, check "Remember me" to stay signed in.
  4. Click "Sign In".
Note: If credentials are incorrect, an error message will appear. Contact your administrator if you need an account.

2.2 Logging Out

Click the "Logout" button in the top-right corner of the navigation bar. You will be redirected to the login page.

3. Dashboard Overview

The Dashboard is the main landing page after login. It provides a complete overview of the petty cash system.

3.1 Summary Statistics

Four key metric cards are displayed at the top:

CardDescription
Total FundsNumber of active fund allocations in the system.
Total BalanceCombined available balance across all funds (of the total allocated).
Total SpentTotal amount spent across all funds, with the number of transactions.
Pending AlertsNumber of replenishment requests awaiting approval.

3.2 Pending Replenishment Alerts

If there are pending replenishment requests, a yellow-bordered card appears showing:

  • Fund number
  • Requested amount
  • Who triggered the request
  • Date of request
  • Approve and Reject buttons (Admin only)

3.3 Petty Cash Funds Table

Lists all petty cash funds with the following columns:

ColumnDescription
FundFund ID number (e.g., #1)
AllocatedTarget fund amount (fixed at ₱30,000)
BalanceCurrent available balance
UtilizationProgress bar showing expense % against the 30% threshold. Color-coded: green (<30%), yellow (30-50%), red (>50%)
StatusActive, To Liquidate, or Pending
ActionsExpense, History, Edit, Delete buttons

Action Buttons:

  • Expense — Create a new expense for this fund
  • History — View all expenses for this fund
  • Edit (Admin) — Edit fund details
  • Delete (Admin) — Delete the fund and all its expenses
  • Add Fund (Replenish) (Admin) — Opens a modal to add funds to the existing balance

3.4 Recent Transactions

A table showing the 10 most recent expenses across all funds. Columns include: Date, Fund, Payee, Category, Particular, Cost Code, Receipt #, Amount, and Actions (Edit button for Admin).

4. Fund Management

4.1 Adding / Replenishing Fund

The system maintains a single fund with a target of ₱30,000.

  1. On the Dashboard, click "Add Fund (Replenish)".
  2. Enter the Amount to Add in the modal.
  3. Click "Create Fund".
Note: Adding funds increases the existing fund's current balance. The fund total is maintained at ₱30,000.

4.2 Editing a Fund

  1. On the Dashboard, click "Edit" next to the fund.
  2. Modify the Allocation Amount.
  3. Click "Update Fund".

4.3 Deleting a Fund

  1. On the Dashboard, click "Delete" next to the fund.
  2. Confirm the deletion in the prompt.
Warning: Deleting a fund removes all associated expenses permanently.

5. Expense Management

5.1 Creating an Expense

  1. From the Dashboard or Fund Expenses page, click "Expense" or "New Expense".
  2. Fill in the required fields:
    • Payee Name (required) — Who received the payment
    • Category (required) — Select from: Supplies, Transportation, Meals, Communication, Office, Maintenance, Other
    • Particular (optional) — Description of the expense
    • Cost Code (required) — Department or project code (e.g., CC-SUP-001)
    • Amount (required) — Expense amount in Philippine Pesos
    • Receipt # (optional) — Reference receipt number
    • Date (required) — Date of the expense
  3. Click "Create Expense".

The fund balance is automatically reduced by the expense amount.

30% Threshold Alert: When total expenses reach 30% of the fund (₱9,000), you will be automatically redirected to create a replenishment report.

5.2 Viewing Expense History

Click "History" on a fund to view all its expenses. The page shows:

  • Summary statistics: Balance, Total Spent, 30% Threshold
  • Full list of expenses with Date, Payee, Category, Particular, Cost Code, Receipt #, Amount, Status, and Actions
  • Each expense shows its status as Open (pending liquidation) or Closed (included in a report)

5.3 Editing an Expense

  1. From the expense history or recent transactions, click "Edit".
  2. Modify any field. The Balance Preview section shows:
    • Original Amount vs. New Amount
    • Difference: +₱X.XX (additional deduction) or -₱X.XX (returned to fund)
    • Projected Fund Balance after the update
  3. Click "Update Expense".

5.4 Deleting an Expense

  1. From the expense history, click "Delete".
  2. Confirm the deletion. The amount is returned to the fund balance.

6. Replenishment Requests

6.1 Creating a Replenishment Request

Replenishment requests can be created in two ways:

  • Auto-Triggered: When expenses reach 30% of the fund (₱9,000), a request is automatically generated.
  • Manual: Go to Replenishments > "New Request", select a fund, enter the amount, and submit.

6.2 Approving / Rejecting Requests

Admin users can manage pending requests from the Dashboard or Replenishments page:

  • Approve — Marks the request as approved, ready for disbursement
  • Reject — Rejects the request

6.3 Disbursing a Replenishment

After approval, click "Disburse" to:

  1. Mark the request as disbursed
  2. Restore the fund balance to ₱30,000
  3. Set the fund status back to Active
Note: After disbursement, the fund is ready for a new cycle of expenses and liquidation reports.

7. Replenishment Reports (Liquidation)

7.1 Creating a Replenishment Report

  1. Go to Replenishment Reports from the sidebar.
  2. Click "New Report".
  3. Fill in the Report Information:
    • Project Name (required)
    • Location (required)
    • Subject (required, default: "Petty Cash Replenishment")
    • Period Start / End (required)
    • Report Date (required, defaults to today)
    • Cash Received (required, auto-filled with total liquidation amount)
    • Prepared By / Reviewed By / Verified By (required)
  4. The Expense Items section is auto-populated with all open expenses:
    • Each row shows: Date, Payee, Cost Code, Particulars, Amount
    • Enter a Voucher No. (required) for each item
    • Optionally enter a Reference No.
  5. The footer shows:
    • Total Liquidated Amount — Sum of all expense amounts
    • For Return / (Reimbursement) — Cash Received minus Total Liquidated
  6. Click "Create Report".
Important: After creating the report, all included expenses are marked as "Closed" and will not appear in future reports.

7.2 Viewing a Report

Click "View" on any report in the list. The report displays:

  • Company header: L.V. LEDESMA CONSTRUCTION, INC.
  • Report details: Project, Location, Subject, Period, Date
  • Liquidation section with Cash Received
  • Itemized expense table grouped by Cost Code and Particulars
  • Total Liquidated Amount and For Return / (Reimbursement)
  • Signature blocks: Prepared By, Reviewed By, Verified By

7.3 Editing a Report

Admin users can click "Edit" on the report view page to modify report details and expense items.

7.4 Exporting to Excel

Click "Download Excel" on the report view page. An .xls file is generated containing:

  • Company header and report information
  • Liquidation table with all expense items
  • Total Liquidated Amount and For Return / (Reimbursement)
  • Signature lines

7.5 Printing a Report

Click the "Print" button on the report view page. The report is formatted for A4 paper with a clean, professional layout. The navigation bar is hidden in print view.

8. Workflow Summary

8.1 Complete Petty Cash Cycle

  1. Fund Setup: Admin creates/replenishes the petty cash fund (₱30,000 target).
  2. Record Expenses: Staff/Admin log expenses as they occur (payee, category, cost code, amount).
  3. 30% Threshold: When total expenses reach ₱9,000 (30%), a replenishment request is auto-triggered and the user is redirected to create a liquidation report.
  4. Replenishment Request: Admin approves and disburses the request, restoring the fund to ₱30,000.
  5. Liquidation Report: Admin creates a formal report listing all open expenses. After creation, those expenses are marked as "Closed".
  6. Export / Print: The report can be downloaded as Excel or printed for physical filing.
  7. Cycle Repeats: The fund is restored, and a new cycle begins.

8.2 30% Threshold Auto-Trigger

The system monitors fund utilization in real-time. When expenses reach or exceed 30% of the ₱30,000 fund:

  • A Replenishment Request is automatically created (if no pending request exists)
  • The user is redirected to create a Replenishment Report
  • The fund status changes to "To Liquidate"
